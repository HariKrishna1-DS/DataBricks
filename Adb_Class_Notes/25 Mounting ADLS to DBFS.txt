
Mounting ADLS to DBFS:
----------------------

-Creating a Storage account(Datalake) and make it available to your dbfs storage


-we need to mount our storage account to dbfs root directory so that we
 can use our own storage account for keeping our data, which will be under
 our control


Mounting ADLS to DBFS :5 steps Process

1)Create ADLS Gen2 storage account in Azure
2)Create Storage Containers in your storage account
3)Create Azure Service principal and secret
        (Azure service principal--->It is a service user account)
        (Secret-->is the password for service user account)

4)Grant access to service principle for storage account
   i,e giving permission to access the storage account or container

5)Goto databricks-->mount storage container

  mount_point = "/mnt/<mount-name>",
  extra_configs = configs)
