In databricks----->Databases or schema both are same

again in database-->we can create-->1)Tables
                                    2)views
                                    3)Functions
                                    4)Volumes

There are 2 types of tables in spark

1)Unmanaged tables or External tables

2)managed tables or internal tables

Tables and Volumes are 2types of objects for storing data physically

Tables:
------
In tables,data is stored in tabular form as a table and data stored in 
data files behind the tables

If you want to acces the data--->through tablename
Tables are of 2 types
1.managed or internal tables: If you drop a table then both metadata and data             
                             both are dropped.

2.un-managed  tables or external tables: If you drop a table then only 
                     metadata will be deleted but still the data remains


volumes:
-------
-These are another type of storage objects-->which can store data files directly

Spark supports storing data in form of tables and working with datafiles such as
parquet file,CSV file,avro file etc

Volumes are of 2 types:
1.un-managed volume :If you delete a volume then spark deletes only metadata 
                    but still the data remains

2.managed volume: If you delete a volume then spark deletes both metadata and 
                  data
