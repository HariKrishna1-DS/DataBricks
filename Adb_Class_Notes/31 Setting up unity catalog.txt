

Setting up unity catalog or Data Governance layer
-------------------------------------------------

-It involves 2 step process

1)1st step is done from the cloud provider i.e from Azure

2)2nd step is done from Databricks workspace.

We need to have atleast one Databricks workspace i.e premium

-in standard workspace,lot of features are not available
------------------------------------------------------------------------------
Unity Catalog set up steps:

1)Create a Databricks workspace(premium)--->myworkspaceadb8am

2)Create Data Storage layer(physical layer) --->done from Azure side
                                                physical data should be stored
                                                in Azure cloud.
    i)create Strorage Account---->mystorageadb8am
   ii)Create Storage Container--->metastore8am-root
  iii)Create Databricks Access connector-->databricks_access_connector8am
   iv)Grant access to Access connector for accessing Azure Storage account

3)Setup Unity Catalog Metastore---->done from Databricks workspace

4)Setup users and permissions-->import users from Active directory and then
                                setup permissions for the user
