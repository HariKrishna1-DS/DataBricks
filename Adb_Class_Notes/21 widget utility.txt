 databricks widgets provides some methods to add arguments

 The most commonly used method is---->text() method

 other methods are:

 1.combobox()
 2.dropdown()
 3.multiselect()
 4.remove(name: String): Removes an input widget from the notebook
 4.removeall--->for removing all widgets in the notebook
 5.get()-->Retrieves current value of an input widget
 6.text(name: String, defaultValue: String)Creates a text input widget with a given name and default value

 The most important method is---->get() method

 get() method allows to read the i/p argument value

 I will use text() method to add text argument to the notebook
