 what is a cluster
   Group of nodes(systems) connected in a network
    There are 2 types of nodes
      1.Driver node 
      2.worker node

      ex: if we have 20-node cluster in that
          one will be the driver and
          all the remaining will be the worker nodes

      Data will be distributed across multiple worker nodes and is
      executed by multiple worker nodes parallely

Defining spark

Spark is a
          -Distributed Execution Framework in
          -parallel process style with
          -in-memory computing feature
          -used for large-scale data processing

In-Memory computation :Here data gets loaded into Ram and gets processed
                       within Ram,
                       here data divided into partitions and the partitions
                       are distributed across multiple rams of multiple worker 
                       machines and are processed parallely
