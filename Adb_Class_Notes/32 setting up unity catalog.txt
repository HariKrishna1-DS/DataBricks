https://accounts.azuredatabricks.net/--> enter externaluser and pwd-->

Name(for metastore): adb9am-meta

Region :Eastus

ADLS Gen 2 path:
syntax:
<container_name>@<storage_account_name>.dfs.core.windows.net/<path>
Optional location for storing managed tables data across all catalogs in 
the metastore.

type this-->
metastore-root@mystoragelakeadb9am.dfs.core.windows.net/
