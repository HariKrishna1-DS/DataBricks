

Job cluster:

Databricks Job:
--------------
1. Job is a process of scheduling a notebook

2.A Job can be executed on-demand/scheduled based

3. A scheduled job executes only on "Job cluster"

4. A Job can be created using UI (or) CLI(command line Interface)

5.A Job cluster terminates automatically when the job is completed

6.A Job cluster cannot restart manually
  Automatically it starts and automatically it gets terminated

  bu we can re-start all purpose cluster

7. A Job cluster is created by "Azure Databricks Job Scheduler" when job is created

8. A databricks job can be executed immediately and manually using all purpose cluster
