In Unity Catalog---->the 1st level of object we create is--->Catalog

                             -databases

Usually we create catalogs for environments or for projects

ex:
You have a project
    -You want to create 2 catalogs-->1)DEV catalog
                                     2)QA catalog

-------------------------
CREATE CATALOG DEV;
-------------------------
or for safety

-------------------------
%sql

dont execute this

First check the--->Catalog Explorer
we see 4 catalogs mainly
1)System catalog--->click-->
                    owner---->system user
                     IT is created automatically for new unity catalog
                     information schema-->click
                     within this we see lot of metadata tables


2)main catalog
      -default  (database/schema)
      information schema

3)samples catalog---->owned by Databricks--->automatically created

4)hive_metastore catalog
  -This is not a unity catalog
  -This is workspace local catalog

  -IF you doesnt have unity catalog setup for ur workspace,
     you will have hive_metastore catalog

  -Once you setup unity catalog
        -we can create new catalogs using unity catalog

         otherwise we will have local workspace catalog i.e hive_metastore
  in hive_metastore,
     whatever objects we create will sit in hive_metastore,which we cannot
     share across multiple workspaces,
