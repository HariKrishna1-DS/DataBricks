creating cluster:
----------------
Now here we need to create a cluster--->with driver and worker nodes

click--->compute--->we see different types of clusters

mainly 3 types of clusters

1)All purpose cluster: we can perform anything here
                used for every program (or) job to run in Databricks session
                This cluster has both Driver and worker nodes 
        It is created,deleted or terminated manually by the user
        
2)Job cluster :It is auto created and deleted or terminated by databricks
               here , we wont see any create button--->for creating this
3)pool cluster-->we can create

==============================================================================
click--->compute---->select--->all purpose cluster--->create compute

Photon--->It is a feature in Azure Databricks that accelerates queries and
          improves performance for diff workloads
                
          This is automatically enabled for cluster running 
          Databricks runtime 9.1LTS and above

Photon offers the following benefits
1) Faster queries :process data faster including joins, aggregation and groupings

2)Improves scan performance : performs better on tables with many columns

3)Fast writing :photon writes tables faster including wide tables with
                thousands of columns

4)Improves AI and ML performance:
   Even more performance for applications using sparksql,sparkDatafrmaes

5)price  and speed performance advantages--->Photon offers
          upto 80% savings and upto 12x speed up
